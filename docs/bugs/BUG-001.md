# BUG-001 — Frete de R$ 19,90 cobrado com subtotal de exatamente R$ 200

**Estado:** confirmado nas evidências fornecidas e reproduzido pelo agente na API. **Requisito violado:** CA06 (limite inclusivo). Cenários CT-002/D02 e CT-004/D04. Não afirmar violação isolada de CA08 ou causa interna.

**Ambiente:** Verzel Store, base `https://verzel-store.qa-test-verzel-store.workers.dev`. Versão documentada 2.3.0, implantada não verificada. UI verificada manualmente no Brave, versão não informada; reprodução do agente via curl, com versão e horários nas evidências JSON.

**Severidade proposta: alta.** Erro em regra central de valor financeiro, acrescentando R$ 19,90 ao total apresentado a um cliente elegível. O fluxo continua utilizável e há valores acima do limite que funcionam, portanto não é bloqueio total. Não há cobrança financeira real neste ambiente. Prioridade de investigação sugerida P1, distinta da severidade.

## Preparação e passos

Catálogo deve manter P005 (Mochila Urbana 20L) a R$ 100. Sem dependência de estado anterior da API.

1. Na UI, preparar carrinho com duas unidades de P005 e sem cupom.
2. Consultar resumo e resposta POST `/api/carrinho/calcular`.
3. Aplicar BEMVINDO10 sem alterar produtos e comparar novamente.

Reprodução API independente, sem criar pedido:

```bash
curl -sS -i 'https://verzel-store.qa-test-verzel-store.workers.dev/api/carrinho/calcular' \
  -H 'Content-Type: application/json' \
  --data-binary '{"itens":[{"produtoId":"P005","quantidade":2}]}'

curl -sS -i 'https://verzel-store.qa-test-verzel-store.workers.dev/api/carrinho/calcular' \
  -H 'Content-Type: application/json' \
  --data-binary '{"itens":[{"produtoId":"P005","quantidade":2}],"cupom":"BEMVINDO10"}'
```

| Condição | Esperado | Observado |
| --- | --- | --- |
| Sem cupom, subtotal 200 | Frete 0, freteGratis true, desconto 0, total 200 | Frete 19,9, freteGratis false, desconto 0, total 219,9 |
| BEMVINDO10, subtotal 200 | Frete 0, freteGratis true, desconto 20, total 180 | Frete 19,9, freteGratis false, desconto 20, total 199,9 |

Ambas as respostas são 200; status é correto para cálculo, os valores de frete/total não são. Faltante zero em resposta/UI torna a orientação inconsistente com a cobrança de frete.

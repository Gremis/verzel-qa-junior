# BUG-002 — API aceita seis unidades do mesmo produto

**Estado:** confirmado por automação de API; cálculo reproduzido também via curl. **Regra:** CA10, máximo de cinco unidades por produto na UI e API. Cenário CT-012, quantidade 6.

**Ambiente:** Verzel Store, versão documentada 2.3.0, implantada não verificada. Playwright 1.64.1, Node 20.19.5, macOS arm64. Responsável pela reprodução: Codex. O bloqueio correto da sexta unidade foi observado na interface; a validação da API falhou.

**Severidade proposta: alta.** Permite confirmar pedido que viola um limite explícito de negócio, ultrapassando a proteção da interface. Sem cobrança/estoque reais neste ambiente; não é indisponibilidade total. Prioridade sugerida P1.

## Reprodução

Precondição: P001 permanece disponível a R$ 59,90. Cada chamada é independente; não exige carrinho anterior.

1. Enviar POST `/api/carrinho/calcular`, JSON com P001 e quantidade 6.
2. Enviar os mesmos itens a POST `/api/pedidos` com cliente fictício válido.
3. Conferir status e conteúdo de cada resposta.

```json
{
  "itens": [{ "produtoId": "P001", "quantidade": 6 }],
  "cliente": { "nome": "Maria Silva", "email": "maria@example.com", "cep": "01310-100" }
}
```

No cálculo, omitir `cliente`. Usar `Content-Type: application/json`.

| Operação | Esperado | Observado |
| --- | --- | --- |
| Cálculo | 422, erro QUANTIDADE_MAXIMA_EXCEDIDA | 200, seis unidades calculadas; subtotal/total 359,40, frete zero |
| Pedido | 422, erro QUANTIDADE_MAXIMA_EXCEDIDA, sem confirmação | 201, pedido fictício confirmado com seis unidades |
